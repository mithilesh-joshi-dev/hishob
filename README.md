# Hishob (हिशोब)

A fast, friendly daily expense tracker for iPhone. Log an expense in seconds with a
dialer-style keypad, see where the money went, and keep your *hishob* — every rupee
accounted for. Built with SwiftUI + SwiftData (iOS 17+).

## Features

- **Quick Add** — big circular keypad with haptics, emoji category picker, optional note
- **Spending dashboard** — spent-today hero, week/month totals, 7-day bar strip, category breakdown with share bars
- **Monthly budget** — set it in Settings; a progress line turns amber at 80% and red when over
- **History** — grouped by Today/Yesterday/date with daily totals; tap to edit, swipe to delete
- **Categories** — 8 defaults seeded on first launch, add/delete your own
- **Multi-currency** — pick a currency in Settings
- **CSV export** — generate and share `hishob-expenses.csv`
- **Siri & Back Tap** — a `LogExpenseIntent` App Intent lets you log without opening the app
- **Widget** — Home Screen and Lock Screen widget showing today's total; tapping it opens Quick Add via the `hishob://add` URL scheme
- **iCloud sync (optional)** — the SwiftData schema is CloudKit-compatible; see below

## Requirements

- Xcode 26 or later with the iOS platform installed
- iOS 17+ simulator or device

## Getting started

1. Open `Hishob.xcodeproj`, select your signing team for **both** targets
   (Hishob and HishobWidget) under Signing & Capabilities, and press ⌘R.
2. ⌘U runs the unit tests.

Signing notes:

- The app and widget share data through the App Group `group.com.mithilesh.hishob`
  (declared in `Configs/*.entitlements` and `Shared/SpendSummary.swift`). Register it
  via Signing & Capabilities on first build, or rename it in those three places.
- Change `bundleIdPrefix` in `project.yml` to your own reverse-domain before shipping.

The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
`project.yml`. After adding or removing source files outside Xcode, regenerate with:

```sh
xcodegen generate
```

## Setting up Back Tap

1. Run the app once so iOS registers its shortcuts.
2. Open the **Shortcuts** app → create a shortcut using the **Log Expense** action.
3. Go to **Settings → Accessibility → Touch → Back Tap** and assign that shortcut to Double Tap.

Double-tapping the back of the phone now logs an expense from anywhere.

## Enabling iCloud sync

Requires a paid Apple Developer account:

1. In `AppModel.swift`, set `cloudSyncEnabled = true`.
2. In Xcode, add the **iCloud** capability (CloudKit) to the Hishob target with
   container `iCloud.com.mithilesh.hishob`, plus **Background Modes → Remote notifications**.

The models already follow CloudKit's rules (no unique constraints, defaults on all properties).

## Structure

```
Hishob/                        # App target
├── HishobApp.swift            # App entry, SwiftData container
├── Models/                    # Expense, ExpenseCategory, shared AppModel
├── Views/                     # ContentView (tabs), Dashboard, QuickAdd, History, Settings
├── Intents/                   # LogExpenseIntent (Siri / Shortcuts / Back Tap)
├── Utils/                     # Theme, currency formatting, CSV export
└── Assets.xcassets            # App icon
HishobWidget/                  # Widget extension target
Shared/                        # SpendSummary — App Group bridge between app and widget
Configs/                       # Entitlements + generated Info.plists
```
