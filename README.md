# TappyClone

A clone of [Tappy – Daily Expense Tracker](https://apps.apple.com/us/app/tappy-daily-expense-tracker/id6777520962) built with SwiftUI + SwiftData (iOS 17+).

## Features

- **Quick Add** — custom keypad, category chips, optional note; log an expense in seconds
- **Spending dashboard** — today / week / month totals, last-7-days bar chart (Swift Charts), monthly category breakdown
- **History** — expenses grouped by day with daily totals, swipe to delete, tap to edit
- **Categories** — 8 defaults seeded on first launch, add/delete your own
- **Multi-currency** — pick a currency in Settings
- **Monthly budget** — set a budget in Settings; the dashboard shows a progress bar (green → orange → red when over)
- **CSV export** — generate and share `tappy-expenses.csv`
- **Siri & Back Tap** — a `LogExpenseIntent` App Intent lets you log without opening the app
- **Widget** — Home Screen and Lock Screen widget showing today's total; tapping it opens Quick Add via the `tappyclone://add` URL scheme
- **iCloud sync (optional)** — the SwiftData schema is CloudKit-compatible; see below

## Requirements

- Xcode 15 or later (install from the Mac App Store)
- iOS 17+ simulator or device

## Getting started

1. Install Xcode, then point the command-line tools at it:
   ```sh
   sudo xcode-select -s /Applications/Xcode.app
   ```
2. Open `TappyClone.xcodeproj`, select your signing team for **both** targets
   (TappyClone and TappyWidget) under Signing & Capabilities, and press ⌘R.

Signing notes:

- The app and widget share data through the App Group `group.com.mithilesh.tappyclone`
  (declared in `Configs/*.entitlements` and `Shared/SpendSummary.swift`). If Xcode
  complains the group is taken, rename it in those three places.
- You may want to change `bundleIdPrefix` in `project.yml` to your own reverse-domain.

The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. After adding/removing source files outside Xcode, regenerate with:

```sh
xcodegen generate
```

## Setting up Back Tap (like the real Tappy)

1. Run the app once so iOS registers its shortcuts.
2. Open the **Shortcuts** app → create a shortcut using the **Log Expense** action.
3. Go to **Settings → Accessibility → Touch → Back Tap** and assign that shortcut to Double Tap.

Now double-tapping the back of the phone logs an expense from anywhere.

## Enabling iCloud sync

Requires a paid Apple Developer account:

1. In `AppModel.swift`, set `cloudSyncEnabled = true`.
2. In Xcode, add the **iCloud** capability (CloudKit) to the TappyClone target with
   container `iCloud.com.mithilesh.tappyclone`, plus **Background Modes → Remote notifications**.

The models already follow CloudKit's rules (no unique constraints, defaults on all properties).

## Structure

```
TappyClone/                    # App target
├── TappyCloneApp.swift        # App entry, SwiftData container
├── Models/                    # Expense, ExpenseCategory, shared AppModel
├── Views/                     # ContentView (tabs), Dashboard, QuickAdd, History, Settings
├── Intents/                   # LogExpenseIntent (Siri / Shortcuts / Back Tap)
└── Utils/                     # Currency formatting, CSV export
TappyWidget/                   # Widget extension target
Shared/                        # SpendSummary — App Group bridge between app and widget
Configs/                       # Entitlements + generated Info.plists
```
